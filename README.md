Online Shopping Management System
This is a simple SQL project created using MySQL to manage an online shopping database.
Project Description
This project stores customer details, product information, and order details. It uses SQL queries to view orders, calculate sales, and check product stock.
Tables Used
- Customers: Stores customer information.
- Products: Stores product names, prices, and stock.
- Orders: Stores order details and status.
- Order Items: Stores products and quantities in each order.
Technologies Used
- MySQL
- SQL
SQL Concepts Used
- CREATE and INSERT
- SELECT and WHERE
- JOIN
- GROUP BY and aggregate functions
- Views
How to Run
1. Open MySQL Workbench.
2. Open the online_shopping.sql file.
3. Connect to your MySQL server.
4. Run the SQL script.
5. Execute the queries to see the results.
Files Included
- online_shopping.sql – Contains the database tables, sample data, and SQL queries.
- README.md – Contains the project details.
